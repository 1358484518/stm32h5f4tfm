禁止使用本目录烧 STM32H5F4。

这里的 bl2.hex / tfm_s_ns_signed.hex 以及 bat 脚本是旧的 STM32H573 布局。
用它们烧 H5F4 会把旧 BL2 写进去，串口只会打印 Starting bootloader（没有 S-sec），
然后卡在第二张镜像的 Boot source: primary slot。

正确步骤（Ubuntu）:
  ./buildtfm.sh test
  cd trusted-firmware-m/build_s/api_ns
  ./regression.sh
  STM32_Programmer_CLI -c port=SWD mode=HotPlug -ob BOOT_UBE=0xB4
  ./TFM_UPDATE.sh

烧完串口必须出现: Starting bootloader S-sec=0x200000
